# M3CH4Ex — Universal Construction Laboratory

Independent experimental workspace for the M3CH4 modular machine builder. This repository is intentionally isolated from the live M3CH4 game.

Open `index.html` through GitHub Pages for the white studio. It has no campaign, combat or live save data.

The laboratory currently supports the existing catalogue's five primary assemblies, graph-backed mounting, a generator outrigger, inspection, exploded views, touch orbit/pinch, and JSON blueprints. Individual leg subsystems and arbitrary attachment topology are future milestones.
